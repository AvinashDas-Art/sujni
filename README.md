# सुजनी · SUJNI

> अनेक धागों से सीती एक सांस्कृतिक पत्रिका  
> कला · संस्कृति · साहित्य · सिनेमा

सुजनी एक हिंदी डेली कल्चरल मैगज़ीन है — दुनिया भर की सांस्कृतिक पत्रकारिता से चुने हुए टुकड़े, हिंदी में **लंबे संपादित सार** के साथ, और हर सार के साथ **मूल स्रोत का लिंक**।

यह रिपोज़िटरी पूरी वेबसाइट का सोर्स है: कंटेंट, डिज़ाइन, स्टैटिक साइट जनरेटर, दैनिक स्रोत-कलेक्टर और मुफ़्त हॉस्टिंग की तैयारी।

## पहला अंक

- 24 टुकड़े, 8,700+ शब्द
- छह धागे: आमुख, सिनेमा, साहित्य, संगीत, नाटक, चित्रकला
- मुख्य निबंध: **एक देश, दो सिनेमा** — ‘रामायण’, ‘गोंधल’ और ‘पायर’ के बहाने भारतीय सिनेमा की दो अर्थव्यवस्थाएँ
- सभी सार मौलिक हिंदी लेखन हैं; मूल अधिकार मूल प्रकाशकों के पास हैं

## चलाएँ

Node 22+ चाहिए। कोई npm डिपेंडेंसी नहीं है।

```bash
npm run build     # dist/ बनाएँ
npm run serve     # http://127.0.0.1:4173 पर देखें
npm run check     # लिंक, सार, RSS, sitemap की जाँच
npm run gather    # आज की स्रोत-शॉर्टलिस्ट data/inbox/ में
```

## ढाँचा

```
content/site.mjs        पत्रिका, अंक, सेक्शन, नेविगेशन
content/edition.mjs     सभी सार, स्रोत, टैग, चित्रांकन-सीड
data/sources.mjs        स्रोत-कैटलॉग (RSS + manual)
scripts/build.mjs       स्टैटिक साइट जनरेटर
scripts/art.mjs         हर टुकड़े का मौलिक SVG चित्रांकन
scripts/gather.mjs      दैनिक RSS/Atom कलेक्टर
scripts/check.mjs       प्रकाशन-पूर्व जाँच
assets/styles.css       डिज़ाइन सिस्टम
assets/app.js           खोज, सहेजें, थीम, सुनें, प्रगति
dist/                   बना हुआ प्रकाशन-योग्य साइट
```

## डिज़ाइन

- **विचार:** सुजनी = सुई-धागे से कढ़ाई करने वाली। पत्रिका अलग-अलग भाषाओं/माध्यमों के धागों को एक कपड़े पर सीती है।
- **टाइप:** Rozha One (प्रदर्शन), Noto Serif Devanagari (पाठ), Tiro Devanagari Hindi (उद्धरण/डेक), Mukta (UI) — सब सेल्फ-होस्टेड।
- **रंग:** काग़ज़, गेरू, नील, हल्दी, जंगल — भारतीय वस्त्रों की पैलेट।
- **चित्र:** कोई स्टॉक फ़ोटो नहीं; हर टुकड़े के लिए जनरेट किया गया मौलिक ज्यामितीय चित्रांकन।
- **सुविधाएँ:** डार्क/लाइट, खोज, सहेजें, साझा, आवाज़ में सुनें, पढ़ने की प्रगति, PWA/ऑफ़लाइन, RSS, sitemap, JSON-LD.
