# स्रोत-सूची

`data/sources.mjs` सुजनी का संपादकीय स्रोत-कैटलॉग है।

- `feed` है तो `npm run gather` उसे अपने-आप पढ़ता है।
- `manual: true` वाले स्रोतों को संपादकीय डेस्क हाथ से देखता है।
- किसी स्रोत को हटाना हो तो `active: false` कर दें।

नया स्रोत जोड़ने से पहले उसका RSS/Atom फ़ीड जाँच लें। सुजनी केवल सार्वजनिक फ़ीड पढ़ती है, पेवॉल या लॉगिन वाली सामग्री नहीं।
